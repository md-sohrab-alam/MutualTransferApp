# Data Safety Form - Play Console

## Data Collection

### Personal Information
- **Name** (optional): Collected from user input
- **Contact method** (if provided): Phone number for authentication
- **Job/Role info**: Post level, designation, subject, qualification
- **School/District preferences**: Current and preferred locations

### Purpose
- **App functionality**: To match teachers for mutual transfers
- **Account management**: User authentication and profile management

## Data Sharing

### Third-party Services
- **Firebase Authentication**: For phone number verification
- **Firebase Firestore**: For data storage
- **Firebase Cloud Messaging**: For push notifications
- **Crashlytics/Analytics**: For app performance monitoring (if enabled)

### Data Sales
- **No data sold**: We do not sell user data to any third parties

## Security Practices

### Data Protection
- Data is encrypted in transit using HTTPS
- Data is stored securely on Firebase
- Users can request data deletion
- Users can update/delete their profile data from within the app

### Permissions Used
- **Internet**: Required for Firebase services
- **Network State**: For connectivity checks
- **Wake Lock**: For push notifications
- **Vibrate**: For notification alerts

### Permissions NOT Used
- Camera
- Microphone
- Location (GPS)
- Storage (external)
- Contacts
- SMS
- Phone state

## User Control
- Users can delete their account by contacting: iamsohrabalam@gmail.com
- Users can update their profile data from within the app
- Users can control notification preferences
- Users can choose what contact information to share
